## Review rules

- Keep `Documentation status` as `Not authored` until both localized pages and every destination anchor exist.
- Change `Screenshot` to `Captured` only after the corresponding localized evidence is recorded in the screenshot manifest and reviewed for test data and sensitive values.
- Change `Review` to `Complete` only after the built site and workflow have been checked in both languages.
