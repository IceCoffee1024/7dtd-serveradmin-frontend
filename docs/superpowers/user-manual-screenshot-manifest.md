## Capture checklist

- Confirm the active console locale matches the manifest route before capture.
- Use a dedicated test environment. Do not add production data or fabricate records merely to make a screenshot.
- Check the full viewport and any crop for identifiers, IP addresses, tokens, passwords, Discord credentials, webhook URLs, and real server filesystem paths.
- Record the viewport, route, console result, and network result in the review record before changing a row to `Complete`.
