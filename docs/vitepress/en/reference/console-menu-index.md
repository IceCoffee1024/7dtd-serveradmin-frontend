# Console menu index

> For server owners and administrators who need to locate a workflow quickly. The index follows the current console route tree, including the hidden Player Profile detail route and the API Documentation entry point.

## How to use this index {#how-to-use}

Use the parent row when a route redirects to its default child. Use a child row when you need a specific tab or settings page. A hidden route is still listed when it is part of an administrator workflow.

| --- | --- | --- | --- |
| Dashboard | — | [/en/daily-operations/dashboard](/en/daily-operations/dashboard) | Check server health, restart timing, quick actions, and recent activity. |
| Player List | — | [/en/daily-operations/players](/en/daily-operations/players) | Find online or historical players and open their administrative workflow. |
| Player Profile | hidden detail | [/en/daily-operations/players#player-profile](/en/daily-operations/players#player-profile) | Review one player's activity, inventory, tracking, and audit context. |
