# 控制台菜单索引

> 面向服主和管理员，用于快速定位工作流。索引按当前控制台路由树编排，包含隐藏的玩家档案详情路由和 API 文档入口。

## 使用方式 {#how-to-use}

父级路由如果会跳转到默认子页，请使用父级行；需要具体标签页或设置页时使用子项行。隐藏路由只要属于管理员工作流，也会在索引中列出。
