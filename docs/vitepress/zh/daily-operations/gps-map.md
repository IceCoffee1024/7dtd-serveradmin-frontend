# GPS 地图

## 适用范围、角色与前置条件

本页面向调查玩家位置、领地、实体或追踪轨迹的管理员。需要 Map Info API、可用的地图渲染/图块和相应模块；在线玩家拖拽传送、领地操作或车辆库存读取还需要更高权限和已加载的游戏区域。

## 目的

GPS Map 是调查和导航辅助面板：把玩家、坐标、世界实体和追踪结果放到同一空间中，再回到玩家画像、控制台或日志确认事实。它不是唯一的管理入口，也不应被当作实时反作弊证据。

## 图层与选择

图层切换器可按需显示：地图图块、Region Grid、Land Claims、Offline Players、Online Players、Animals、Hostiles、Traders、Vehicles、Drones，以及从 Player Tracking 打开的轨迹覆盖层。实体弹窗可能显示位置、状态、所有者、燃料或库存；车辆库存只在后端可读且车辆已加载时可用。

## 操作流程

1. 打开 GPS Map，先确认地图背景、坐标控件和游戏时间出现；若地图为空，先检查地图渲染设置、Map Info API 和后端连接。
2. 在图层切换器只打开调查所需层，点击在线/离线玩家或实体标记查看弹窗。通过玩家名和稳定 Player ID确认目标，不要只依赖聚合图标或 Entity ID。
3. 读取鼠标位置/最后点击坐标，记录 X/Z（或界面显示的坐标）和地图缩放级别。用同一坐标回到玩家追踪、领地或事件记录核对。
4. 从玩家画像的 Tracking 或区域搜索进入地图时，检查时间范围、中心 X/Z、半径和最小距离；轨迹覆盖层应与查询条件一致。
5. 需要导航时把 GPS 作为辅助动作，回到 Player Profile、Player List 或日志完成管理决策。若界面提供拖拽在线玩家标记传送，必须再次确认玩家、目标坐标和维护授权后才提交。

## 可观察的验证

- 图层开关只影响对应标记；点击标记后弹窗中的玩家/实体身份、坐标和状态与后端列表一致。
- 坐标控件在点击地图后更新，追踪覆盖层显示的起止时间和目标玩家与画像查询一致。
- 地图刷新或短暂断线后，重新加载可恢复图块和可用实体；不可用图层显示为空或加载失败，不被伪造为零实体。

## 限制与安全

- 地图数据受后端采样、地图渲染、聚合、加载区域和刷新间隔影响；离线玩家和历史轨迹不等于实时位置。
- 坐标、领地、车辆和库存是敏感数据；共享截图前隐藏玩家 ID、IP、服务器坐标和文件路径。
- 拖拽传送、移除领地、刷新/渲染完整地图都有副作用或耗时。完整地图渲染可能持续数分钟并在控制台输出进度，通常只在需要时执行。
