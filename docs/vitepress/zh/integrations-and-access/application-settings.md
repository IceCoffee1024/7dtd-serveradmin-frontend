# 应用设置

> 面向负责 ServerAdmin 后端连接和会话策略的管理员。这些值影响应用和认证边界，而不只是单个游戏功能。

## 目的 {#purpose}

设置应用使用的后端 Web 地址、服务器账号凭据、Token 生命周期和服务器配置文件引用。

## 开始前 {#before-you-begin}

- 从部署交接中取得目标后端地址和账号。在示例中使用 `<SERVERADMIN_API_BASE_URL>`、`<SERVERADMIN_ADMIN_USERNAME>`。
- 确认当前账号可以更新应用设置，并安排第二位运维人员在 Web URL 或密码错误时协助恢复。
- 预先决定会话生命周期或后端地址变更后是否需要前端刷新或重新登录。
- 控制台语言切换只改变前端标签，可能需要刷新前端；不会改变后端时区或任何 Cron 计划。
- 不要把真实密码、Token、数据库路径或私有配置路径粘贴到文档、截图或浏览器环境变量中。

## 操作步骤 {#procedure}

1. 打开 **应用设置**，等待已有值加载。页面摘要显示 Web URL、用户名和服务器配置文件，不会在概览中显示密码。
2. 填写完整的 `http://` 或 `https://` Web URL、后端用户名和服务器密码。表单会校验必填字段以及 URL 格式。
3. 以秒为单位设置访问 Token 和刷新 Token 的过期时间。在满足运维流程的前提下使用较短生命周期，并记录长生命周期的原因。
4. 将服务器配置文件引用设为 `<SERVER_CONFIG_FILE>` 或部署审批的相对路径。实际路径由后端解析，不要根据浏览器机器猜测本地路径。
5. 点击 **保存设置**。要放弃未保存值时，在离开页面前点击 **重置**；存在未保存更改时页面会提示确认。
6. 从后端重新读取设置。Token 过期时间变更会作用于新签发的会话；退出再重新登录，才能让当前账号使用新的访问/刷新 Token 生命周期。语言切换需要刷新前端才能更新标签，但不会改变后端时区或计划任务行为。修改地址时同步更新反向代理和前端环境。

## 验证结果 {#verify-result}

- 重新读取后显示预期的 URL、用户名、过期时间和配置文件引用。
- 前端可以访问 `<SERVERADMIN_API_BASE_URL>`、完成认证、加载仪表盘并打开受保护功能。
- 新会话按设定生命周期过期；只有刷新 Token 仍有效时，过期的访问 Token 才能续期。
- 退出并重新登录后，新会话使用保存的 Token 生命周期；切换界面语言并刷新后只改变可见标签，后端计划和时区不变。
- 服务器配置页可以读取目标文件，且审计消息不会泄露文件内容。

## 限制与安全说明 {#limits-and-safety}

::: danger
错误的 URL、密码或文件引用可能让所有运维人员无法登录，或让应用指向错误服务器。请第二位运维人员复核目标，并在新会话验证前保留旧值。
:::

::: warning
Token 过期值的单位是秒，会影响活动会话。后端地址改变后通常需要刷新前端，会话改变后通常需要退出再登录才能观察效果。
:::
