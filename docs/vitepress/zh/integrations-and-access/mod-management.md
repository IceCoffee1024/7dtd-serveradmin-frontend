# 模组管理

> 面向可以查看服务器已发现模组并切换模组状态的管理员。安装文件仍属于服务器发布流程；本页主要用于运行时清单和状态核对。

## 目的 {#purpose}

将模组清单与已审批的部署清单对照，识别版本或加载状态漂移，并在兼容性复核后才变更模组状态。

## 开始前 {#before-you-begin}

- 确认服务器和游戏版本、已审批模组清单，以及维护窗口内可用的回滚包。
- 确认账号能读取模组元数据和切换模组。页面有一行数据不代表模组一定兼容当前游戏版本。
- 变更可能影响方块、实体、存档或网络行为的模组前，先备份服务器配置和世界。

## 操作步骤 {#procedure}

1. 打开 **模组管理** 并等待表格加载。可按显示名称、内部名称、作者、描述或目录名搜索。
2. 查看 **模组**、**作者**、**版本**、**网站**、**已加载** 和 **已安装** 列。目录名是状态请求使用的稳定键。
3. 将每行与审批清单对照，并阅读模组作者的兼容性说明。外部网站属于不可信输入，只应在受控的运维浏览器中打开。
4. 变更已获批准后，使用行操作切换模组状态。等待成功结果并重新加载表格；上一个请求未结束时不要再次点击。
5. 模组或加载器要求时重启游戏服务器。保留旧包和备份，直到测试世界或计划中的冒烟验证通过。

## 验证结果 {#verify-result}

- 刷新后行显示预期的 **已加载** 和 **已安装** 状态，目录名与审批清单一致。
- 游戏日志没有模组加载或依赖错误，专用测试账号可以连接并操作受影响功能。
- 模块中心和仪表盘显示相关功能可用；如果仍不可用，回滚切换并恢复已知可用包。

## 限制与安全说明 {#limits-and-safety}

::: warning
表格只反映请求时后端和游戏进程报告的状态，不会解析第三方模组的依赖顺序、许可证兼容性或二进制完整性。
:::

::: danger
切换或替换模组可能改变世界数据，甚至导致服务器无法启动。执行前安排维护窗口，保留备份，并明确回滚负责人。
:::
